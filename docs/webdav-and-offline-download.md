# WebDAV 与离线下载使用指引

- WebDAV：把你的 R2 存储桶挂载成「网络磁盘」，用任意 WebDAV 客户端直接读写。**仅限 Node / Docker 自托管版**。
- 离线下载：粘贴一个文件直链，服务器在后台下载并转存到你的 R2 桶。**Node / Docker 版为完整版；Workers 版为受限版（仅支持小文件，见文末对比）**。

---

## 一、WebDAV（Node/Docker 版）

### 1. 基本信息

| 项目 | 说明 |
| --- | --- |
| 挂载点 | `http://你的主机:3000/dav/` |
| 认证方式 | HTTP Basic，**用户名任意**（如 `any`），**密码 = 网页登录密码**（`AUTH_PASSWORD`） |
| 目录结构 | 根集合 `/dav/` = 当前激活账号下的所有桶；`/dav/桶名/路径` 即桶内文件 |
| 激活账号 | WebDAV 读写的是网页里「当前激活」的那个账号，切换账号后挂载看到的内容随之变化 |

### 2. rclone

```bash
# 配置远程（用户名随便填，密码是登录密码）
rclone config create r2x webdav \
  url=http://localhost:3000/dav/ \
  vendor=other \
  user=any \
  pass=$(rclone obscure 你的登录密码)

# 直接读写
rclone lsd r2x:            # 列出所有桶
rclone ls r2x:桶名/目录    # 列出文件
rclone copy 本地文件 r2x:桶名/路径   # 上传
rclone copy r2x:桶名/文件 本地目录   # 下载

# 挂载为本地磁盘（Linux/macOS，需要 FUSE）
rclone mount r2x: /mnt/r2 --vfs-cache-mode writes
```

### 3. macOS Finder

1. 打开「访达」→ 菜单「前往」→「连接服务器…」（⌘K）
2. 输入 `http://主机:3000/dav/`
3. 弹出认证时：用户名任意（如 `any`），密码填登录密码

### 4. Windows 资源管理器

1. 「此电脑」→ 右键「映射网络驱动器」
2. 文件夹填 `http://主机:3000/dav/`（勾选「使用其他凭据连接」）
3. 认证时：用户名任意，密码填登录密码

> Windows 的 WebDAV 客户端（ WebClient 服务）默认限制单文件 ≤ 50MB 且要求 HTTPS，大文件建议改用 rclone。其他第三方客户端（RaiDrive、Cyberduck 等）无此限制。

### 5. 支持的操作与边界

| 支持 | 不支持 / 注意 |
| --- | --- |
| 列目录（PROPFIND）、读文件（GET/HEAD，支持 Range 断点） | **删除桶**：桶只能进网页里删，WebDAV 根集合为只读 |
| 上传（PUT，流式直传，大文件不吃内存）、改文件 | 空目录：R2 没有真实目录概念，空目录用零字节对象标记兜底，行为可能与传统文件系统有细微差异 |
| 删除文件/目录（DELETE，目录递归） | 修改权限/元数据（PROPPATCH 仅返回成功但不实际生效） |
| 新建目录（MKCOL）、复制/移动/重命名（COPY/MOVE，含目录递归） | 文件锁（LOCK）为内存实现，服务重启后锁失效 |
| 排他锁（LOCK/UNLOCK，部分客户端需要） | |

## 二、离线下载

### 1. 是什么

在文件列表工具栏点「**离线下载**」，粘贴一个 `http/https` 文件直链，服务器会在后台下载该文件并转存到你的 R2 桶——

- Node/Docker 版：分块直传，**全程不落盘**，支持 GB 级大文件
- Workers 版：单次流式直传，**仅支持小文件**（默认上限 100MB，见文末对比）
- 你可以关掉网页，任务继续跑

### 2. 使用步骤

1. 进入目标目录（保存位置 = 当前所在目录），点工具栏「离线下载」
2. 粘贴文件直链，系统会**自动探测**：识别文件名（优先读响应头的 Content-Disposition）、大小、类型
   - 探测失败也没关系（部分服务器不接受探测请求），仍可手动填写文件名后创建任务
3. 确认文件名（可改名），点「开始下载」
4. 任务列表实时显示进度、速率；可以最小化弹窗，任务继续
5. 下载完成后文件自动出现在当前目录（列表自动刷新，有完成通知）

### 3. 任务管理

| 操作 | 说明 |
| --- | --- |
| 取消/删除 | 进行中的任务点「取消」会中断下载并清理已上传的分片；已结束的任务点「删除」仅从列表移除 |
| 重试 | 失败或已取消的任务可一键重试，从头开始（不支持断点续传） |
| 排队 | 同时最多 **2 个**任务在下载，其余自动排队 |
| 清理 | 「清理已完成」一键移除所有已结束的任务 |
| 防重复 | 相同目标路径的任务进行中时，不允许再次创建 |

### 4. 限制与注意

- **仅支持 http/https 直链**，不支持磁力/BT/FTP；链接必须能公开访问（需要登录/Referer 校验的链接无法下载）
- 目标文件名会覆盖同名已有对象，注意确认
- 下载任务绑定创建时的 R2 账号；账号被解绑后任务执行会失败
- Workers 免费版有额外限制（体积上限、任务不可中断等），见文末对比表

### 5. 常见问题

**Q：粘贴链接后提示「探测失败」？**
部分服务器不支持 HEAD 请求或拦截探测，不影响创建任务——只要真实下载能访问即可。直接手动填好文件名，点「开始下载」。

**Q：下载完成的文件在哪？**
在你打开弹窗时所在的目录（弹窗内「保存到」有显示）。想换位置，先切到目标目录再点「离线下载」。

**Q：能不能下载到其他桶？**
保存到「当前激活账号」的当前桶。需要其他桶，先在顶部切换存储桶并进入对应目录。

**Q：下载速度慢/失败？**
取决于服务器到源站的网络。失败原因会显示在任务行上（如 HTTP 状态码），可据此判断是链接失效还是网络问题。

## 三、平台支持对照

### 功能可用性

| 功能 | Node/Docker 版 | Workers 免费版 | Workers 付费版 |
| --- | --- | --- | --- |
| WebDAV | ✅ | ❌ | ❌（无法提供常驻 WebDAV 服务） |
| 离线下载 | ✅ 完整版 | ⚠️ 受限版 | ⚠️ 受限版（上限可调高） |

### 离线下载：Node 版 vs Workers 版

| 能力 | Node/Docker 版 | Workers 版（免费/付费通用实现） |
| --- | --- | --- |
| 文件体积 | ~80GB（8MB 分片 × 10000） | 默认 **100MB**，`OFFLINE_MAX_SIZE_MB` 变量可调 |
| 传输方式 | multipart 分片，流式零落盘 | 单 PUT 流式直传（不分片，省子请求） |
| 未知大小的直链 | ✅ 支持（边下边传） | ❌ 要求直链带 Content-Length |
| 取消进行中任务 | ✅ 立即中止并清理 | ❌ 仅移除记录，后台会跑完 |
| 重试 | ✅ | ✅ |
| 服务重启影响 | 未完成标记失败可重试 | 无此概念（任务状态在 KV，不随服务重启丢失） |
| 并发 | 2 个任务 | 不限（单次请求内互不干扰） |
| 进度/速率实时性 | ~1 秒 | ~15 秒（节流写 KV，省请求额度） |

### Workers 平台限制来源（为什么免费版只能下小文件）

| 资源 | 免费版 | 付费版（$5/月起） | 对离线下载的影响 |
| --- | --- | --- | --- |
| CPU 时间/请求 | 10ms | 默认 30s，可调至 5min（等待网络不计入） | 流式转发几乎不占 CPU，但大文件仍有超限被杀（Error 1102）的风险 |
| 子请求数/请求 | 50 | 10,000 | 免费版预算：源站 fetch + R2 PUT + 进度写 ≈ 48，刚好够单文件直传 |
| 内存/isolate | 128MB | 128MB | 单 PUT 流式不占内存；分片缓冲方案不可行 |
| KV 写入/天 | 1,000 | 100 万 | 每个任务约 20 次进度写，免费版一天约 50 个任务 |

**实践建议**：

- 免费版把 `OFFLINE_MAX_SIZE_MB` 保持在 ≤200（超 CPU 限制的风险随体积上升，任务会标记失败）
- 需要下载大文件、WebDAV 或更可靠的体验 → 用 Node/Docker 自托管版
- Workers 版定位是轻量免运维部署，适合日常小文件的转存场景

### Workers 版配置

```toml
# wrangler.toml [vars] 中可选调整体积上限（MB），默认 100
[vars]
OFFLINE_MAX_SIZE_MB = "100"
```

另外需要 `ACCOUNTS_KV` KV namespace 绑定（任务状态存储），未绑定时界面上「离线下载」入口自动隐藏。
